فکرِ حق ایپ انسٹال کرنے کا آسان طریقہ

بغیر کسی بھاری یا الگ APK فائل کے اپنے فون کی ہوم اسکرین پر ہلکی پھلکی اور تیز رفتار ایپ شامل کیجیے

مرکزی بٹن یا براؤزر سے انسٹال کریں

  1. سب سے پہلے اپنے براؤزر (مثلاً Google Chrome) میں فکرِ حق کی ویب سائٹ کھولیں: https://FikreHaq.github.io
  2. ویب سائٹ کے مرکزی صفحہ پر موجود ایپ ڈاؤن لوڈ / انسٹال بٹن پر کلک کریں؛ اگر براہِ راست پرامپٹ نہ آئے تو براؤزر کے اوپر یا نیچے دائیں کونے میں موجود تین نقطوں (⋮) کے مینو پر کلک کریں۔
  3. کھلنے والی فہرست میں Install app یا Add to Home screen کے آپشن پر کلک کریں۔
  4. تصدیقی باکس میں Install یا Add دبا دیں۔
فائدہ: یہ ایپ کروم براؤزر کے نظام سے چلتی ہے، اس لیے انتہائی ہلکی، کم وسائل استعمال کرنے والی اور تیز رفتار ہے۔ انسٹال ہونے کے بعد فکرِ حق کا آئیکن ہوم اسکرین پر آ جائے گا جہاں سے آپ براہِ راست اور باآسانی بیانات و مواد تک پہنچ سکیں گے۔

کمپیوٹر اور آئی فون پر طریقہ

  1. کمپیوٹر / لیپ ٹاپ (Chrome یا Edge): ویب سائٹ کھول کر ایڈریس بار کے Install آئیکن یا مینو سے Install فکرِ حق منتخب کریں۔
  2. آئی فون / آئی پیڈ (Safari): Safari میں ویب سائٹ کھول کر نیچے یا اوپر Share بٹن دبائیں اور Add to Home Screen منتخب کریں۔
  3. انسٹال یا ایڈ ہونے کے بعد نئے آئیکن سے ایپ کھول کر باسہولت استعمال کریں۔
اہم احتیاط: چونکہ یہ ایپ کروم براؤزر کی بنیاد پر کام کرتی ہے، اس لیے ایپ انسٹال کرنے کے بعد Google Chrome کو ہرگز Uninstall نہ کیجیے گا؛ بصورتِ دیگر یہ ایپ بھی ختم ہو جائے گی یا نہیں چل سکے گی۔

ویب سائٹ اور ایپ کو اپڈیٹ کرنے کا تفصیلی طریقہ

موبائل، کمپیوٹر اور انسٹال شدہ ایپ میں نیا مواد فوراً دیکھنے کے لیے محفوظ اور آسان طریقے

موبائل پر کیشے صاف کرنے کا محفوظ طریقہ

اس طریقے سے آپ کی براؤزنگ ہسٹری اور پاسورڈ محفوظ رہتے ہیں۔

  1. اپنے موبائل کی Settings (سیٹنگز) میں جائیں۔
  2. وہاں سے Apps (ایپس / ایپلیکیشنز) کے آپشن پر کلک کریں۔
  3. ایپ لسٹ میں اپنا براؤزر (مثلاً Google Chrome) تلاش کر کے کھولیں۔
  4. اس کے بعد Storage (اسٹوریج) کے سیکشن میں جائیں۔
  5. وہاں Clear Cache (کلیئر کیشے) کے بٹن پر کلک کر دیں۔
اہم تنبیہ: صرف Clear Cache کرنا ہے؛ Clear Data یا Clear Storage ہرگز نہ کریں تاکہ آپ کا محفوظ شدہ ڈیٹا اور لاگ انز متاثر نہ ہوں۔

کمپیوٹر یا لیپ ٹاپ پر ویب سائٹ تازہ کرنے کا طریقہ

بغیر کسی سیٹنگ کو چھیڑے صرف کی بورڈ شارٹ کٹ سے صفحے کو تازہ ترین حالت میں لائیں۔

  1. کمپیوٹر یا لیپ ٹاپ کے براؤزر میں فکرِ حق کا صفحہ کھولیں۔
  2. کی بورڈ سے Ctrl + F5 دبائیں (بعض براؤزرز میں Ctrl + Shift + R بھی کام کرتا ہے)۔
  3. صفحے کے مکمل لوڈ ہونے کا انتظار کریں تاکہ سرور سے تازہ ترین فائلیں آ جائیں۔
ہارڈ ریفریش کا فائدہ: اس عمل سے براؤزر پرانی محفوظ فائلوں کے بجائے براہِ راست سرور سے نئی اپڈیٹس اور نیا مواد لوڈ کرتا ہے، جبکہ آپ کی ہسٹری اور ذاتی ڈیٹا محفوظ رہتا ہے۔

ہوم اسکرین ایپ کو تازہ رکھنے کا طریقہ

چونکہ فکرِ حق ویب ایپ براؤزر کے انجن سے چلتی ہے، اس لیے اپڈیٹ کے بعد اسے تازہ کرنا نہایت آسان ہے۔

  1. نئی اپڈیٹ کے بعد پہلے کھلی ہوئی ایپ کو مکمل بند (Close) کر دیں۔
  2. موبائل کی سیٹنگز میں جا کر متعلقہ براؤزر کا Clear Cache کریں۔
  3. براؤزر ری سٹارٹ کر کے ہوم اسکرین سے ایپ کھولیں تاکہ نئے بیانات اور تبدیلیاں نظر آ سکیں۔
نتیجہ: ان مراحل کے بعد ویب سائٹ اور ایپ تازہ ترین اور اپڈیٹڈ صورت میں میسر ہوں گی، جن میں نئے بیانات اور سہولیات شامل ہیں۔
